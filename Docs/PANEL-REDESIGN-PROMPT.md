# Промпт для дизайнера-AI: редизайн HP2 Machinima Panel

Скопируй текст ниже целиком в чат с дизайнером-AI.

---

Ты — UI/UX-дизайнер + WPF-верстальщик. Сделай улучшенный макет и XAML для уже работающей панели управления камерой при съёмке внутриигрового видео (machinima) в игре 2002 года. Панель — always-on-top утилита, висит поверх игры на втором мониторе/в углу; пользователь при этом управляет камерой в игре. Дизайн должен быть компактным, тёмным, читаемым, с крупными главными кнопками.

## Контекст использования

Оператор летает свободной камерой по уровню игры (стрелки+мышь), в нужных местах ставит ключевые кадры (F8 или большая кнопка), потом проигрывает пролёт по кадрам и записывает видео. Работает в двух режимах внимания: (а) руки в игре, взгляд в игру — важны глобальные хоткеи и краткая статусная строка; (б) руки в панели — редактирование таблицы кадров и параметров.

## Полный список функций (ничего не терять)

1. Шапка: название «HP2 MACHINIMA PANEL», перетаскивание окна за всю шапку, кнопка закрытия X.
2. Подсказка по глобальным хоткеям: F8 — добавить кадр, F9 — play (по скоростям кадров), F10 — стоп, F11 — очистить. Важно: работают, когда фокус в игре.
3. HideHud — скрыть игровой HUD. Esc (close menu) — закрыть игровое пауза-меню. CamMode 9 — свободная камера (деградировавшая функция, можно уменьшить/убрать в «доп. настройки»).
4. ADD KEYFRAME — главная кнопка (ставит кадр с текущими координатами камеры, углами, FOV и скоростью полёта из поля).
5. Два режима проигрывания пути:
   - PLAY (by TIME): весь путь за N секунд — поле «FLIGHT TIME, SEC» (по умолчанию 15);
   - PLAY (by keyframe SPEEDS): каждый сегмент летит со скоростью, записанной в его кадре.
   - Stop — остановить проигрывание.
6. Таблица ключевых кадров (DataGrid, 9 колонок): # / Time (чч:мм:сс) / X / Y / Z / Yaw / Pitch / FOV / Speed (редактируется прямо в ячейке — единственная редактируемая колонка). Двойной клик по строке — камера прыгает к кадру.
7. Refresh table — принудительная ресинхронизация таблицы. Go to selected — прыжок к выбранному кадру. Delete selected — удалить выбранный кадр.
8. FOV: поле (по умолчанию 90) + кнопка Set FOV — применить FOV к камере немедленно (для кинематографичного вида).
9. Скорость: поле «fly speed» (по умолчанию 500) + Set fly speed; кнопка «Speed → key» — присвоить её выбранному кадру; кнопка «Speed → ALL» — применить ко всем кадрам.
10. List — вывести список кадров в игровой лог (отладочная, можно в «доп.»).
11. Clear — удалить ВСЕ кадры (разрушительное действие).
12. Статусная строка — результат последнего действия («PathAdd OK 21:39», «table: 5 keys (memory scan OK)»).
13. Чекбокс «Transparent» — прозрачность панели 80% (видеть игру за панелью).

## Проблемы текущего макета (исправить)

- Слишком высокий (~1000px): растянуть в более компактный/плотный макет, желательно ≤ 600px высоты при ширине ~560-640px.
- Кнопки «Speed → key» / «Speed → ALL» / Set fly speed дублируют смысл — сгруппировать в одну ясную зону «Speed».
- Clear (разрушительное) стоит рядом с безобидными Stop/List — отделить, добавить подтверждение не нужно (у него есть хозяин-хоткей), но визуально пометить.
- Нет индикатора состояния игры (запущена ли игра) и режима (запись пути / проигрывание) — добавь компактный статус-бар с индикатором-точкой.
- PLAY vs ADD KEYFRAME: главная кнопка — ADD KEYFRAME, её должно быть видно мгновенно.

## Технические ограничения (строго)

- Целевая платформа: Windows Presentation Foundation, XAML, который грузится через XamlReader в PowerShell 5.1 (один файл, без code-behind и без событий в XAML — все обработчики навешиваются кодом по Name).
- Сохрани Name у всех контролов: BtnHideHud, BtnCam9, BtnEscMenu, BtnPathAdd, TbSeconds, BtnPathPlay, BtnPathPlaySpeed, BtnPathStop, BtnPathList, BtnPathClear, DgKeys, BtnRefresh, BtnGoto, BtnDel, TbFov, BtnSetFov, BtnKeySpeed, TbSpeed, BtnSpeed, BtnSpeedAll, CbTransparent, HdrGrid, BtnClose, TbStatus. Если добавляешь новые — перечисли.
- DataGrid с колонками: Num, Time, X, Y, Z, Yaw, Pitch, FOV, Speed; IsReadOnly=False только у Speed; биндинги: {Binding Num} и т.д.; DataGridColumnHeader стилизуется через Window.Resources.
- Окно: Topmost=True, WindowStyle=None, AllowsTransparency=True, ResizeMode=NoResize, Width ~560-640, фон #F21E1E2E (полупрозрачный тёмный), шрифт таблицы Consolas.
- Цветовая база: Catppuccin Mocha (#1E1E2E фон, #313244 элементы, #CDD6F4 текст, акценты #A6E3A1 зелёный, #F9E2AF жёлтый, #89DCEB голубой, #F38BA8 розовый, #CBA6F7 фиолетовый, #F5C97B оранжевый, #94E2D5 мятный) — можешь обогатить, но оставь тёмную тему с высоким контрастом.
