# HP2 Machinima Panel — полная спецификация (v4.11)

Панель управления камерой-машинимой для игры Harry Potter and the Chamber of Secrets (M212 engine).
Технология: PowerShell 5.1 + WPF (один XAML в .ps1 файле), без компиляции.
Окно: 560px ширина, высота по контенту (~1000px), Always-on-top, NoResize, прозрачность.
Тема: Catppuccin Mocha (тёмная).

## Структура сверху вниз

1. **Шапка (кастомная, WindowStyle=None)** — перетаскивание за любое место, справа крестик X (закрыть).
2. **Строка хоткеев** (жёлтый текст): `F8 AddKey | F9 Play | F10 Stop | F11 Clear` — глобальные хоткеи, работают когда фокус в ИГРЕ (не в панели).
3. **3 кнопки**: HideHud (спрятать HUD) | CamMode 9 (свободная камера — сейчас почти не нужна, включается сама) | Esc (close menu — закрыть игровое меню).
4. **ADD KEYFRAME (PathAdd)** — большая зелёная. Главное действие: ставит кадр (позиция+углы+FOV+скорость). Перед постановкой применяет скорость из бокса fly speed.
5. **Поле FLIGHT TIME, SEC** (по умолчанию 15) + кнопка **PLAY (by TIME)** — проиграть весь путь равномерно за N секунд.
6. **PLAY (by keyframe SPEEDS)** — проиграть путь, где каждый сегмент летит со скоростью своего кадра.
7. **3 кнопки**: Stop | List | Clear (очистить все кадры).
8. **Таблица кадров (DataGrid)** — 9 колонок:
   - `#` — номер кадра
   - `Time` — чч:мм:сс постановки (сохраняется между запусками панели)
   - `X, Y, Z` — координаты камеры (1 знак после запятой)
   - `Yaw, Pitch` — углы взгляда (единицы движка UE: 65536 = 360°)
   - `FOV` — угол обзора кадра
   - `Speed` — скорость сегмента от этого кадра (ЕДИНСТВЕННАЯ редактируемая колонка, правка в ячейке уходит в игру)
   Двойной клик по строке = камера прыгает к кадру (предпросмотр).
9. **3 кнопки**: Refresh table (полная ресинхронизация) | Go to selected (прыжок к выбранному кадру) | Delete selected (удалить кадр).
10. **Ряд FOV**: поле `90` + Set FOV (применить FOV к камере сейчас) + Speed -> key (присвоить выбранному кадру скорость из бокса ниже).
11. **Ряд fly speed**: поле `500` (по умолчанию) + Set fly speed (скорость свободного полёта камерой).
12. **Speed -> ALL keyframes (value from box above)** — применить скорость из бокса ко всем кадрам разом.
13. **Низ**: строка статуса (последнее действие/результат) + чекбокс **Transparent** (прозрачность 80%, чтобы видеть игру за панелью).

## Как это работает внутри (важно для UX-логики)

- Источник данных таблицы: панель сканирует память игры (лог-события PATHEV с монотонными номерами), кадры всегда синхронны с игрой.
- Обновление таблицы: быстрое (~0.3с) после действий; Refresh table = полный скан (~2с).
- Все кнопки активируют окно игры, открывают игровую консоль (`` ` ``), вводят команду (Unicode-ввод), Enter, закрывают консоль.
- Команды НЕ работают, когда открыто игровое меню (pause) — для этого кнопка Esc (close menu).
- Кадры хранятся в игре; панель ничего не хранит кроме времён постановки (key-times.txt).

## Существующие проблемы UX (то, что хочется улучшить)

- Слишком длинная вертикаль (~1000px) — не всегда помещается на экран рядом с игрой.
- Дублирование смыслов: «Speed -> key» и «Speed -> ALL» и редактирование в таблице; «CamMode 9» почти не нужен (авто); «List» — отладочная.
- Кнопки Stop/List/Clear не сгруппированы по опасности (Clear разрушает, но выглядит как сосед).
- Нет индикации подключения к игре (запущена/нет) и состояния (идёт проигрывание/стоит).
- Поле FLIGHT TIME и кнопки PLAY/TIME vs SPEED можно скомпоновать яснее.
- Хоткеи упомянуты, но нет визуальной подсказки, что они работают только при фокусе в игре.

## Технические ограничения редизайна (критично)

- Один файл PowerShell + XAML (XamlReader), без code-behind, без зависимостей.
- Все Name= контролов и набор обработчиков должны сохраниться (или быть перечислены в маппинге).
- DataGrid обязателен (редактируемая колонка Speed, только она).
- Обязательны: Topmost, прозрачность (AllowsTransparency), drag за шапку, глобальные хоткеи F8-F11, строка статуса.
- Ряды кнопок — любые (UniformGrid/Grid/TabPanel), но логика кнопок не меняется.
